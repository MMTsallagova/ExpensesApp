# Расходы — Марго и Миша

Приложение для учёта расходов на двоих (Япония, ¥): коммуналка, подписки, связь, продукты со сканированием чеков, статистика и рекомендации по питанию.
Работает как PWA: ставится на главный экран Android и iPhone, данные общие и синхронизируются мгновенно.

## Из чего состоит

| Файл | Что это |
|---|---|
| `index.html` | всё приложение |
| `config.js` | адрес и публичный ключ Supabase (заполнить один раз) |
| `vendor.js` | библиотеки Supabase и Anthropic (собраны в один файл) |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на телефон и работа без сети |
| `setup.sql` | создание таблицы и правил доступа в Supabase |

## Настройка (один раз)

### 1. Supabase — база данных
1. Зарегистрируйтесь на https://supabase.com → **New project**. Регион — **Northeast Asia (Tokyo)**. Пароль базы сохраните.
2. **SQL Editor → New query**: вставьте содержимое `setup.sql`, **замените почту** на свою (Мишу можно добавить позже — строка в конце файла), нажмите **Run**.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email** (иначе придётся подтверждать почту по письму).
4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public** в `config.js`.

Доступ к данным есть только у почт из таблицы `members`, даже если кто-то найдёт сайт.

### 2. GitHub Pages — где лежит приложение
Репозиторий → **Settings → Pages → Source: Deploy from a branch → main / (root)**. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

### 3. Ключ Claude API — для чеков и рекомендаций
1. https://console.anthropic.com → **Billing**: пополните баланс (хватит $5 надолго).
2. **API Keys → Create key**, скопируйте ключ.
3. В приложении: **⚙ настройки → Ключ Claude API → Сохранить**. Вводится один раз, у второго человека появляется автоматически.

Один скан чека стоит примерно ¥5–10 (модель Claude Opus 5.5).

## Установка на телефон
- **Android (Chrome):** открыть адрес → меню ⋮ → **Установить приложение** / «Добавить на главный экран».
- **iPhone (Safari):** открыть адрес → кнопка **Поделиться** → **На экран «Домой»**.

Первый вход: каждый нажимает **Создать аккаунт** со своей почтой (той, что добавлена в `members`) и паролем. Дальше — **Войти**.

## Обновление
Изменения в файлах, отправленные в `main`, появляются на телефонах при следующем открытии приложения.
